What the code does

Calculation pipeline

1

Market data

im_data_pipeline.py loads spots, historical returns, LSEG surfaces and proxy volatility inputs.

2

Physical proxy

im_prisma_proxy.py reprices futures/options under scenarios and computes a local initial margin.

3

ML calibration

train_calibration_model.py learns the correction between the local proxy and official PRISMA margins.

4

Portfolio engine

im_margin_engine.py aggregates legs, applies the ML factor and handles portfolio netting.

5

Validation

validation_multidate_suite.py replays portfolios and compares hybrid margins with PRISMA API labels.

Worked example

P029 - Directional future, 2023-05-19

-3x FSTX 2023-06-16
1

Retrieve the traded product

The API gives the listed instrument, maturity and net long/short balance. Here the position is a short STOXX Europe 600 future in liquidation group ETD-INDEX.

2

Compute the local proxy margin

Historical returns are volatility-filtered, converted into MPOR spot scenarios, then the future is repriced in every scenario. 

r* = r × clip(current_EWMA_vol / long_run_vol, 0.5, 2.0)
S_s = S0 × exp(sum(r*) over MPOR)
F_s = S_s × exp((r - q) × T)
V_s = quantity × multiplier × F_s
loss_s = -(V_s - V0)
proxy_IM = max(Q99(loss), Q99.9(loss), 0.1% × notional, add-ons)

Applied to P029: proxy margin = 5,617.76 €.

For options, the scenario repricing step uses Black-Scholes/Black-76 with the LSEG volatility surface: option_value_s = BS(S_s, K, T, r, q, σ(K,T)).

3

Apply the ML calibration factor

The model learns a log correction between the local proxy and official PRISMA unit margins. 

target = log(API_margin / local_proxy_margin)
predicted_factor = exp(model(features))
hybrid_standalone = proxy_margin × guarded(predicted_factor)

P029 factor: 1.2995, so 5,617.76 € × 1.2995 = 7,300.20 €.

4

Aggregate at portfolio level

The engine recomputes the portfolio under the same scenario grid, so opposite positions can offset through scenario P&L. The retained hybrid margin then applies the robust ML factor to this netted portfolio proxy. 

robust_portfolio_factor = guarded weighted average of ML factors
final_hybrid = portfolio_proxy × robust_portfolio_factor

The portfolio_proxy already contains scenario-level netting because positions are valued together before the loss quantile is computed. The robust factor is the final ML multiplier for the portfolio: it averages the leg-level ML corrections, weighted by their risk contribution, and caps unstable predictions so the final margin stays economically reasonable.

P029 has one leg, so the retained robust factor is 1.2995. The final robust hybrid = 7,300.20 €.

5

Compare with PRISMA

Local proxy5,617.76 €
Hybrid ML7,300.20 €
PRISMA API6,442.84 €
Abs. error13.31%

This example is intentionally directional: it isolates the proxy and calibration mechanics. Multi-leg portfolios use the same formulas, but netting can materially reduce the portfolio proxy before the final ML factor is applied.

Calibration layer

Model and target

The retained calibration model is a scikit-learn HistGradientBoostingRegressor. XGBoost support remains in the engine only as a backward-compatibility fallback for older model artefacts.

Training target log(API margin / local proxy margin)

At inference, the model predicts a log correction. The hybrid unit margin is then: local_margin_scaled × exp(predicted_log_ratio).
